BoundedContext Lending { domain { Aggregate LoanApplication { applicationId uuid identity; applicantId string required; requestedAmount decimal min 1000; creditScore int min 300 max 850; status text default DRAFT; submittedAt datetime optional; approvedAt datetime optional. State machine for status has DRAFT initial, SUBMITTED, APPROVED, REJECTED final, WITHDRAWN final. DRAFT can move to SUBMITTED when applicant data is complete. SUBMITTED can move to APPROVED only when credit score at least 650 and requested amount is under policy limit. SUBMITTED can move to REJECTED when risk too high. DRAFT or SUBMITTED can move to WITHDRAWN always. operations { when submitting application with submittedAt: applicantId requestedAmount and creditScore are required; then status becomes SUBMITTED and submittedAt is copied; emit LoanApplicationSubmitted. when approving application with approvedAt: status is SUBMITTED, creditScore greater than 650, requestedAmount greater than 0; then status APPROVED and approvedAt set; emit LoanApplicationApproved. } } } events { submitted event applicationId uuid submittedAt datetime. approved event applicationId uuid approvedAt datetime. } repositories { LoanApplicationRepository supports findById optional and save. } specifications { ApprovableLoan means status SUBMITTED and creditScore greater than 650. } }
