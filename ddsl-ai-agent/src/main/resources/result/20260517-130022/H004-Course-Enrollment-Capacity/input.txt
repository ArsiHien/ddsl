BoundedContext Learning { domain { Aggregate CourseOffering { offeringId uuid identity, courseCode text required, instructorId text required, capacity int min 1, enrolledStudents set of StudentEnrollment, waitlistedStudents list of StudentEnrollment, status text default DRAFT. StudentEnrollment entity: enrollmentId uuid identity, studentId string required, enrolledAt datetime required, status text. operations { when publishing offering: courseCode instructorId and capacity are required; then status PUBLISHED. when enrolling student with studentId and enrolledAt: status must be PUBLISHED and studentId required and enrolledStudents count below capacity; then create StudentEnrollment with studentId and add it to enrolledStudents; emit StudentEnrolled. when waitlisting student with studentId and enrolledAt: status PUBLISHED and enrolledStudents count is at capacity; then create enrollment and add to waitlistedStudents; emit StudentWaitlisted. } } } events { StudentEnrolled offeringId uuid studentId string enrolledAt datetime. StudentWaitlisted offeringId uuid studentId string waitlistedAt datetime. } repositories { CourseOfferingRepository findById optional, findByCourseCode list, save void. } specifications { OpenForEnrollment means status PUBLISHED and enrolledStudents less than capacity. } }
